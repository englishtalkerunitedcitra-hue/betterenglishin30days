# betterenglishin30days
Better English in 30 Days karya Mr B membantu pembelajar dewasa yang sudah mengenal dasar English tetapi masih ragu berbicara. Dengan latihan 10–15 menit per sesi, 12 bab, tantangan harian, habit tracker, ungkapan praktis, dan ringkasan grammar, kamu diajak membangun kebiasaan serta keberanian menggunakan English. Mulai dari satu kalimat sederhana
